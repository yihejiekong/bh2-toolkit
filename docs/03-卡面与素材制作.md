# 03 · 卡面与素材制作

所有卡面都是 **HTML + headless 浏览器截图**：先用 Python 生成 HTML，
再用 Edge/Chrome 无头模式按 2 倍缩放截图，最后按背景色裁掉底部空白。
这样排版、字体、渐变都能直接用 CSS 写，比 PIL 画图快得多。

## 目录约定

```
tables/     图鉴表 xlsx
materials/  成品素材（脚本输出到这里）
  ├─ 装备卡/{装备卡,徽章卡,服装卡,使魔卡}/PNG/
  ├─ 图标/  觉醒立绘/  看板小图/  表情差分/  萌章图标/  词条图标/
  ├─ 角色卡/  玩家名片/  精英技能/{cards,gif}/  僵尸娘/{cards,gif,icons}/
data/       解包产物（tsv_all 等）
build/      构建中间物（HTML、截图临时目录）
```

路径统一由 `cards/paths.py` 给出，脚本里不要写死绝对路径：

```python
import paths as P
P.MATERIALS, P.TABLES, P.XLSX, P.BUILD, P.BROWSER, P.FONT_BD
```

## 装备类卡面

| 脚本 | 产出 | 差异 |
|---|---|---|
| `cards/cardgen.py` | 武器卡 HTML | 基准模板：属性块、技能条、觉醒块 |
| `cards/costume.py` | 服装卡 | 属性块只有 负重/生命/亲密度上限，类型写「类别」 |
| `cards/badge.py` | 徽章卡 | 属性块只有 负重/亲密度上限，类型固定「徽章」 |
| `cards/pet.py` | 使魔卡 | 属性块 攻击力/暴击率 + 词条图标行 + 技能类型标签与 CD |
| `cards/build_chara_cards.py` | 角色卡 | 角色立绘 + 语音/介绍排版；资源取自官网 `chara/{id}/`，每张卡的排版参数单独调过（见 [06](06-素材来源一览.md)） |

批量出图：

```bash
python cards/batch.py            # 武器（默认全部）
python cards/batch.py --ids 897,21178
python cards/batch_fz.py         # 服装
python cards/batch_badge.py      # 徽章
python cards/batch_pet.py        # 使魔
python cards/_verify_batch.py    # 逐张比对渲染高度，检查有没有被裁
```

`batch.py` 会做：同名去重（取最高星级 + 最高等级）→ 准备素材 →
轮换 edge profile 并发截图（失败重试）→ 按背景色裁底 → 写 PNG。

## 卡面的几个固定套路

* **属性块**：值为 0 的属性直接不渲染，避免一屏 `0`。
* **技能条**：浅蓝斜纹底 + 白字蓝描边标题，右侧放类型标签（奥义/觉醒/自律/固有）。
* **觉醒块**：角色名、身高·三围·生日、爱好、介绍、台词、立绘。
  立绘缺失时**降级**：先试 FigureID 大图，再试「看板小图」，都没有就不画立绘。
* **星级**：用 ★ 文本，不用图片，方便改。

## 觉醒立绘的兜底链

```
xlsx 的「觉醒立绘文件」 → 立绘ID → partnerposterdata 查 FigureID → 觉醒立绘/<fid>_*.png
                                                  └→ 看板小图/<fid>.png（240px，模糊但全）
```

`PosterID` 与 `FigureID` 差 1000 这件事必须处理，否则会把
「1014 某个角色」的图错挂到「2014」上。

## 从官网数据现做的两套素材

这两套不依赖解包，直接抓官网攻略站，任何人可复现（全部来源汇总见 [06-素材来源一览.md](06-素材来源一览.md)）：

### 精英技能（58 项）

```bash
# 1) 抓清单 + 图标（新克隆必须先跑一次）
python cards/build_skill_card.py --fetch
# 2) 单卡 + 演示动图（按编号）
python cards/build_skill_card.py 1 2 3
# 3) 全量预渲染（同时生成 index.json，机器人读它）
python cards/batch_skill_cards.py
# 4) 汇总图（6 列网格，256 色压缩后约 540 KB）
python cards/build_elite_sheet.py
```

数据源：`POST https://www.benghuai.com/data/getData`，
表单 `type=elite_skill&page_num=1&page_size=500`，返回 `id/name/icon/display_img/skill_desc/guide/tips`。
清单存 `materials/精英技能/elite_skill.json`，图标存同目录 `<id>.png`。

### 僵尸娘（58 只）

```bash
python cards/build_zombie.py 57      # 单只：资料卡 + 合并演示动图（首次运行会自动拉清单）
python cards/batch_zombie.py         # 全量（4 线程，约 1 分钟）
python cards/build_zombie_sheet.py   # 汇总图 + 重建 index.json
```

数据源：`getData` 的 `type=zombie`，详情走 `getDataByID?id=<id>&type=zombie`。
清单缓存在 `$BH2_BUILD/zombie_all.json`，删掉会重新抓。

**多技能不刷屏的核心**：不管几只技能，永远只发两条消息 ——
一张资料卡（全部技能文案）+ 一张合并动图（各技能演示纵向拼接，
每段带 `01 技能名` 标签条）。合并规则：

* 每段统一缩到 360 宽，高度按比例；
* 帧数不同时短段取模循环补齐；
* 隔帧取样（`STEP=2`）+ 96 色量化，把 3.7 MB 压到 1.8 MB；
* 标签条用 PIL 直接画（浏览器排版在逐帧拼接时对不齐）。

## 截图参数

```bash
msedge --headless=new --disable-gpu --hide-scrollbars --no-first-run \
       --force-device-scale-factor=2 --window-size=1040,2600 \
       --screenshot=out.png file:///path/card.html
```

* `--window-size` 的高度要**足够大**，否则长卡会被截断（本项目踩过：
  僵尸娘汇总图 8 行只截到 4 行，因为窗口高给的 900）。
* 截完图按背景色扫最后一行非背景像素，裁掉下方空白；
* 并发截图时每个进程用独立的 `--user-data-dir`，否则互相抢 profile 会随机失败。
