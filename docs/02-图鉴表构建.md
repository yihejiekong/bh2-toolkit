# 02 · 图鉴表构建

卡面脚本读的是一张 xlsx（默认 `tables/bh2_codex.xlsx`，可用 `BH2_XLSX` 覆盖）。
这张表本身是从解包数据整理出来的，本仓库不附带游戏数据，需要自己生成或用
自己的表，只要**列名一致**即可。

## 表结构

| sheet | 内容 | 关键列 |
|---|---|---|
| `武器` | 武器图鉴 | 内部ID / 名称 / 星级 / 类型 / 图标文件 / 技能 / 觉醒立绘文件 … |
| `服装` | 战斗服 | 内部ID / 名称 / 星级 / 类别 / 图标文件 … |
| `使魔-被动技能` | 徽章（游戏内叫被动技能装备） | 内部ID / 名称 / 星级 / 图标文件 … |
| `宠物` | 使魔 | 内部ID / 名称 / 星级 / 奥义 / 自律 / 固有 / 词条ID / 词条效果 … |
| `词条` | 使魔词条字典 | 词条ID / 词条名 / 图标ID / 稀有度 / 最高等级 / 效果说明 |
| `汇总` / `变更明细` / `别名明细` … | 说明与审计页 | — |

## 数值换算（最容易搞错的地方）

解包文本里的技能数值是「1 级值 + 每级增量 + 每破增量」，写成
`基础(+a每级/+b每破)`，例如 `120.5(+6.5每级/+12每破)`。

```
满级 X = 基础 + a × (MaxLv − 1)
满破 Y = X + b × 10
卡面显示 X(Y)，没有「每破」项就只显示 X
```

增量可能是负数（`15(-0.5每破)` → 满破 10），正则在 `cardgen.expand_params()` 里，
`([+-]?\d+(\.\d+)?每[级破])` 必须允许负号，否则会少展开一批卡。

## 文本清洗

解包文本里夹着客户端控制码：

* `#n` / `#c` 之类的占位与换行控制
* `<color=...>`、`</color>` 标签

统一走 `cardgen.clean()`，否则卡面上会看到 `#n` 这种东西。

## 配置表读取

`cards/bh2data.py` 是薄封装：

```python
hdr, rows = read_tsv("data/tsv_all/weapondatav3.txt")   # 自动跳过中文名/类型说明行
tm = load_textmap()                                     # 文本 id -> 文本
```

`read_tsv` 会从第 2 行往后找第一行「首列是数字」的数据行，所以多种不同
行数的表头都能吃。

## 已知的坑

1. **同一行自增列**：脚本会给 sheet 追加列（例如「词条ID」「奥义初始CD」）。
   重复在同一张已追加过的表上跑，会变成 95 列。改表前先备份，跑之前从备份还原。
2. **5★/6★ 同名两条记录**：装备表里同名的两张卡是两个不同条目，
   按「内部ID」去重，不要按名字去重。
3. **`PetCharacter` 是词条 id 列表**，形如 `6;12;13`，`0` 表示空槽；
   槽位数量由星级决定（4★ 0–1、5★ 1–2、6★ 2、7★ 3）。
4. **`petcharacterdata.txt` 的 `Desc` 列装的是词条名，`ShortDesc` 才是效果**，
   两列名字反了，别按列名理解。
